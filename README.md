# Интернет-магазин

## Описание:



## Цель проекта:

Создать интернет-магазин

## Установка:

Клонируйте репозиторий:

```
git clone https://github.com/username/project-x.git
```

Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Пример работы с функциями:

1. Класс `Product` создает объект продукта с его характеристиками (название, описание, цена, количество)
2. Класс `Category` создает объект категории, содержащий список продуктов, и обновляет глобальные счетчики 
   категорий и продуктов
3. Классы `Smartphone и LawnGrass` наследуют все свойства базового класса Product

## Тестирование

Для тестирования функционала используется фреймворк pytest. Тесты находятся в директории tests и покрывают основные
функции проекта.

Для запуска тестов выполните команду:

```
pytest
```

## Описание тестов:

1. **Тестирование** `test_init`: проверяет корректность инициализации объекта Product
2. **Тестирование** `test_init_category`: проверяет корректность создания объекта Category
3. **Тестирование** `test_product_price_set`: тестирует валидацию цены через property
4. **Тестирование** `test_add_product_category`: тестирует добавление товаров в категорию и обновление счетчиков
5. **Тестирование** `test_smartphone_init`: проверяет специфичные атрибуты смартфонов
6. **Тестирование** `test_lawn_grass_init`: тестирует атрибуты газонной травы
7. **Тестирование** `test_base_product_is_abstract`: проверяет невозможность создания BaseProduct
8. **Тестирование** `test_creation_logger_mixin`: тестирует логирование создания объектов
9. **Тестирование** `test_product_add`: проверяет сложение стоимости товаров
10. **Тестирование** `test_invalid_product_add`: тестирует обработку ошибок при неверных операциях
